## Reproduction

In this repository, run:

```sh
cd research/erdos488/route-audit
python3 verify.py --output results.json
cd ../lean
lake update
lake exe cache get
lake env lean RouteAudit.lean
```

In the downloadable standalone package, run `python3 verify.py --output results.json`
from its root, then `cd lean` and run the same Lake commands. The package retains
the previous Rounded.lean and project configuration to reproduce the identical
dependency environment; no new check of the older Rounded theorem is claimed
by this workflow. The Python checker uses only the standard library and explicit
checks that remain active under Python optimization.

refuted. Their proposed sufficient routes to the main problem cannot be used
