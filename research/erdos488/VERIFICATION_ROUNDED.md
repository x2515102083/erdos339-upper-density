## Reproduction

From `research/erdos488`:

```sh
python3 all_scales_check.py --n-max 20 --self-test
python3 independent_verify.py all-scales-n20-certificates.jsonl 20
cd lean
lake update
lake exe cache get
lake build
lake env lean Rounded.lean
```

The two Python checks use only the standard library. Do not enable Python's
`-O` or `PYTHONOPTIMIZE`. Lean requires the toolchain named in `lean-toolchain`;
the package pins Mathlib to the selected upstream commit. The successful
workflow is the exact reproduction reference, including the axiom audit.

No official catalog, eligibility, claim, candidate, recipient, or award record
was changed. A complete arbitrary-generator proof or an exactly verified
counterexample remains necessary for a complete solution.
